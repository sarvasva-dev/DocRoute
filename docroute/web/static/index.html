Native PDF Extraction

High-speed vector PDF parsing via PyMuPDF at ~17ms per page with 100% vector accuracy.

👁️

OpenCV + Tesseract OCR

Automated Otsu binarization, deskew angle correction, and multi-language OCR (English + Hindi).

📊

2D Table Matrices

Bounded and borderless table grid detection returning structured 2D matrices and cell coordinates.

🧠

Quality-Based Routing

Automatic quality fallback routing based on text density, printable ASCII ratio, and scan score.

🎯

Page-Level Provenance

Full traceability mapping every text string to bounding box coordinates `[x0, y0, x1, y1]` and engine source.

🔌

Developer REST API

Versioned `/v1/ocr` endpoint with Pydantic schemas, Swagger UI, and copyable code snippets.

About DocRoute Architecture

Technical design of the adaptive document extraction pipeline.

DocRoute is an open-source adaptive document intelligence engine combining vector PDF extraction (PyMuPDF), computer vision preprocessing (OpenCV), and OCR (Tesseract) with quality-based fallback routing.
